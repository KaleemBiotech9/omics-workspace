# 🧬 Multi-Omics Data Analytics Workspace

A modular, zero-budget ecosystem built with Python and Streamlit to streamline computational biology workflows, data exploration, and molecular docking management.

## 🚀 Features

*   **📊 Exploratory Data Explorer:** Instantly generates statistical summaries and visual distributions from raw biological datasets (CSV).
*   **🧪 CADD Workflow Tracker:** A local SQLite-powered database to log, organize, and search molecular docking parameters and binding affinities (e.g., AutoDock Vina, PyRx).
*   **📄 Automated Report Builder:** Aggregates database logs to identify optimal ligand/target pairs and exports clean research summaries as CSV or PDF.

## 🛠️ Tech Stack
*   **Frontend & Routing:** Streamlit
*   **Data Processing:** Pandas & NumPy
*   **Visualization:** Matplotlib
*   **Database:** SQLite3

## 💻 Local Installation

1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Launch the ecosystem: `streamlit run app.py`
